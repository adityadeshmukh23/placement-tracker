 
# Placement Tracker

A command-center style web app to track placement preparation progress at IIT Kanpur.

## Features

- Track companies, roles, and application statuses
- Monitor preparation across DSA, Core, and HR rounds
- Clean, minimal UI built with pure HTML & CSS
- Responsive design for desktop and mobile

## Tech Stack

- HTML5
- CSS3 (custom design tokens, responsive layout)
- Vanilla JavaScript

## Usage

Open `index.html` directly in any browser — no setup or server required.
